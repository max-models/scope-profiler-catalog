## What this is

<CardGrid>
	<Card title="From files to a website" icon="rocket">
		A YAML manifest lists profiling files. `scope-profiler site` turns them into a page per case and per run, with charts, hotspot tables and scaling plots.
	</Card>
	<Card title="A proper site" icon="open-book">
		Astro and Starlight, with search, a sidebar, light and dark themes and stable and dev channels, from the same theme as the other max-models projects.
	</Card>
	<Card title="Made to be forked" icon="setting">
		Fork it, replace the sample data step with your own, enable GitHub Pages. A workflow fetches the files, builds the pages and deploys.
	</Card>
</CardGrid>
